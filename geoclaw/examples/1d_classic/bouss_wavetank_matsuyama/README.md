### Matsuyama wave tank experiment

This example corresponds to Section 6.2 of the paper.
The starting point for this setup was the example in the GeoClaw repository: https://www.clawpack.org/gallery/_static/geoclaw/examples/1d_classic/bouss_wavetank_matsuyama/README.html

To generate the data run `bash run_automated.sh`. To generate Figure 12 in the paper, run `python plot_gauges_HSGN.py`.
